Description

Magic is a class-based PvP game built around a strong competitive design philosophy. The core objective is to deliver an easy to play, hard to master experience, where mechanical skill, game knowledge, and strategic decision-making matter as much as reflexes.

The game places a strong emphasis on competitive gameplay, with clear class identities, counter-based interactions, and balanced mechanics designed to minimize randomness. An in-game progression and economy system allows players to make meaningful build choices, adding depth and long-term replayability without compromising competitive integrity.

Players use spells, abilities, and items with custom behaviors, all designed to reward mastery, positioning, timing, and smart resource management.

The project was designed with the following objectives:

    Design an accessible game, easy to understand and play from the first match
    Provide a high skill ceiling, rewarding mastery, game knowledge, and precise execution
    Build a competitive environment with minimal randomness, focusing on balance, counterplay, and player decision-making
    Ensure strong replayability, through multiple game modes, progression systems, rankings, and long-term goals (farming, unlocks, experimentation)
    Push the technical limits of vanilla Minecraft, exploring advanced datapack, resource pack, and UI mechanics without mods

Core Features

    4 playable classes, each with unique abilities, spells, and cooldown management
    Class counter triangle, where each class has strengths and weaknesses against others, encouraging strategic picks and team composition
    In-game economy and build choices, allowing players to invest resources into different upgrades and playstyles, shaping the match meta
    Custom items with unique behaviors and skill-based usage
    6 custom competitive maps, with a strong focus on level design, flow, and map-specific mechanics
    Custom UI elements via resource pack and shaders, designed for clarity in competitive play

Getting Started
Dependencies

    Minecraft Java Edition 26.2
    Magic Map v1.34
    Datapack & Resource Pack (this repository)

Installing

    Download the repository
    Place the datapack inside: /saves/Magic_Map/datapacks/
    Merge the resource pack content into your Minecraft resource packs folder: /resourcepacks/
    Launch Minecraft and enable the resource pack
    Load the Magic map
